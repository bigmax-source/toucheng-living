# 頭城生活中｜頭城生活指南 — Build015

**Since 2026/08/07**  
**Build015：2026/08/27**

這是一個由《頭城二三事》持續整理的頭城生活資料網站，收錄餐飲、醫療照護、生活服務、居家修繕與交通接送等在地店家與服務資訊。

## Build015 現況

- **店家與服務：114 筆**
- 瀏覽器分頁：`🌊 頭城生活中｜頭城生活指南`
- 主分類骨架：餐廳、早午餐、晚餐、小吃、點心、飲料、咖啡、醫療照護、生活服務、居家修繕、交通接送
- 支援店名、地址、推薦品項與特色標籤搜尋
- **「素食」正式作為飲食特色標籤**，不另拆主分類
- 店家詳細頁 / Living Card / 圖片輪播
- Google Maps 導航、收藏、分享
- 「我要加入」與 7 步驟 Living Card 資料補充流程
- LocalStorage 保存草稿與收藏
- 店家照片以 WebP 為主，降低網頁載入量

## 排序與營業狀態

- 首頁採 **「即時營業優先＋Session 隨機排序」**。
- 同一個瀏覽 Session 內排序保持穩定；開啟新 Session 才重新洗牌。
- 支援跨午夜營業時段判斷。
- 營業中店家優先顯示；無法確認營業時間者顯示「營業時間等待店家補充」。
